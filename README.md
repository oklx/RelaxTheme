# RelaxTheme
A minimalist, typography-focused Typecho theme designed for study notes and technical writing. Features include a clean layout, built-in dark mode, enhanced styling for code blocks and math formulas, plus convenient reading tools like a Table of Contents.

> 一款极简、注重排版的 Typecho 主题，专为学习笔记与技术写作设计。特点包括清爽的布局、内置深色模式，对代码块和数学公式进行了样式美化，并提供文章目录等便捷阅读工具。
